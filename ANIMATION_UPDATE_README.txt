HOW TO UPDATE THE EXISTING GITHUB REPOSITORY
1. Download and extract this ZIP.
2. Open your existing repository: https://github.com/Samad72/luna-base-mission-trainer
3. Open each file in the repository and use the pencil/Edit button, or upload the three files from the extracted folder.
4. Replace the existing index.html, style.css and app.js with the matching files in this ZIP. Do not create a nested folder. Keep all other project documents and the PowerPoint.
5. Commit the changes to the same publishing branch (normally main).
6. Wait a few minutes, then refresh the live site with Ctrl+F5. GitHub Pages republishes when changes are pushed to its configured publishing source.

The NASA DONKI API feature and the educational-simulation disclaimer are retained.
